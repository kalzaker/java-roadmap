# Player Inventory System (Консольное RPG приложение)

Простое консольное приложение на Java для управления инвентарем персонажа, разделенное на уровни `model` и `service`.

## Конфигурация инвентаря по умолчанию
* Количество слотов: **5**
* Лимит веса: **50.0 кг**

## Доступные предметы в системе
1. **Яблоко** (Вес: 0.2кг, Стек: до 10 шт)
2. **Зелье** (Вес: 0.5кг, Стек: до 5 шт)
3. **Меч** (Вес: 5.0кг, Стек: до 1 шт)

## Список интерактивных команд

* `add <название> <количество>` — Добавляет предмет в инвентарь (автоматически упаковывает в стеки и проверяет вес).
    * *Пример:* `add яблоко 15` (Займет один полный стек из 10 яблок, а 5 оставшихся перенесет в следующий слот).
* `remove <индекс_слота> <количество>` — Удаляет указанное количество предметов из конкретного слота.
    * *Пример:* `remove 0 3`
* `move <индекс_откуда> <индекс_куда>` — Перемещает предмет в пустой слот или объединяет стеки одинаковых предметов.
    * *Пример:* `move 0 2`
* `search <название>` — Ищет предмет по части имени (регистронезависимо) и выводит список слотов, где он лежит.
    * *Пример:* `search зел`
* `help` — Вывести список доступных команд.
* `exit` — Завершить выполнение программы.
